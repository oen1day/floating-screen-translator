# Changelog

## 1.11.3

- Added Sakura 7B Japanese-to-Simplified-Chinese translation in an isolated
  process.
- Added direction-aware `日→中` strength selection.
- Added KV prefix caching, six-thread defaults, and optional ARM
  dot-product/i8mm builds.
- Added exact OCR duplicate-line merging.
- Added configurable model download, size, and SHA-256 verification.
- Improved HyperOS accessibility overlay recovery and target-window capture.

## Earlier internal builds

Earlier versions added region selection, floating-panel resize/collapse,
ML Kit OCR/translation, local small-model fallback, cloud API mode, and
vendor-specific capture workarounds.
